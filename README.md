# Task 1 – Spam Email Detection using Machine Learning

## Objective
To build a machine learning model that classifies messages as Spam or Ham.

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Random Forest

## Project Description
This project uses machine learning techniques to detect whether a message is spam or ham. Text data is processed using TF-IDF and machine learning models are trained to classify the messages.

## Environment Setup
This project can be run using Google Colab.

Required Python libraries:
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Upload the required dataset.
3. Run the notebook cells in order.
4. Check the model results and predictions.

## Files
- `spam error detection.ipynb` – Main project notebook
- `Task1_Report.pdf` – Project report

## Result
The machine learning models classify messages into Spam and Ham categories and their performance is evaluated using accuracy and precision.

## Conclusion
The project demonstrates how machine learning and TF-IDF text processing can be used for spam email detection.
